**Campus Event Manager**

* Overview

Campus Event Manager is a responsive web platform designed to simplify event organization and participation within a university environment.
It allows administrators to easily add and manage events,
while students can explore upcoming activities and register with just a few clicks.

* Features

   Event Listing: Displays all campus events in a clean, organized layout.

   Admin Panel: Enables administrators to add, edit, or remove events effortlessly and maintain record of student register for event.

   Registration Form: Lets students register for events directly through the website.

   JSON Integration: Stores event data dynamically without requiring a database.

   Responsive Design: Works smoothly across desktop and mobile devices with a modern purple theme.

* Tech Stack

   Frontend: HTML, CSS, JavaScript

   Data Handling: JSON server

   Tools: VS Code, DevTools

* Purpose

  This project demonstrates how modern web technologies can streamline campus event management. It’s built as a prototype for learning,
  portfolio presentation, and showcasing web development skills.
